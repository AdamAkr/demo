# Charazatydanya — website demo

This is a static demo of the Charazatydanya online shop. It needs no server or database.
Everything works in the browser: the 3 languages, search, filters, cart, checkout, coupons and the card payment flow.

- Demo orders are saved only in the visitor's own browser. Nothing is sent anywhere, and no real payment happens.
- Coupon codes to try: **WELCOME10** (10% off orders over 20,000 IQD) and **EID5000** (5,000 IQD off orders over 40,000 IQD).

## Publish on GitHub Pages
1. Create a new **public** repository on GitHub.
2. Upload **all files in this folder** to it, including the `.nojekyll` file, and commit.
3. Open **Settings → Pages** and set **Source** to "Deploy from a branch", branch **main**, folder **/ (root)**. Save.
4. After about a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.
